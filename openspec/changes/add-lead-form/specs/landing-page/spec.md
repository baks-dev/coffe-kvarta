## MODIFIED Requirements

### Requirement: Оболочка секции заявки
Секция `#lead-form` SHALL показывать надзаголовок «Заявка», заголовок «Оставьте заявку», вводный текст, упорядоченный список из трёх шагов, место для формы и строку «Удобнее позвонить?» со ссылкой на телефон мастерской. Пока форма не передана, место для формы MUST NOT показывать заглушку, а строка с телефоном MUST оставаться. Главная страница `/` MUST передавать в это место форму заявки.

#### Scenario: Без формы
- **WHEN** компонент секции отрисован без формы
- **THEN** секция показывает заголовок, вводный текст «Корзины и оплаты на сайте нет. Оставьте телефон — менеджер перезвонит, уточнит заказ и день доставки.», шаги «Вы оставляете заявку», «Мы перезваниваем и уточняем детали», «Привозим в пятницу или ждём в мастерской» и строку «Удобнее позвонить? +375 (29) 123-45-67»; текстов вида «скоро», «в разработке» или «TODO» нет

#### Scenario: С формой
- **WHEN** в секцию передан элемент формы
- **THEN** форма отрисовывается между списком шагов и строкой с телефоном

#### Scenario: Форма заявки на главной странице
- **WHEN** запрошен HTML страницы `/`
- **THEN** внутри `#lead-form` после списка шагов и перед строкой «Удобнее позвонить? +375 (29) 123-45-67» есть `<form>` с подписью поля «Телефон»

### Requirement: Работа без JavaScript
Весь контент секций SHALL быть доступен при отключённом JavaScript. Якорные ссылки MUST работать как обычные переходы по хешу. Из компонентов секций MUST выполнять клиентский код только ссылки, передающие намерение заявки, и форма заявки. При отключённом JavaScript форма заявки MUST оставаться видимой, её кнопка отправки MUST быть неактивной, а рядом MUST быть сообщение с телефоном мастерской.

#### Scenario: JavaScript отключён
- **WHEN** JavaScript в браузере отключён и открыта страница `/`
- **THEN** видны все секции с текстами, ценами и фото, а ссылки шапки, hero и подвала прокручивают к своим секциям

#### Scenario: Форма заявки без JavaScript
- **WHEN** JavaScript отключён и посетитель прокрутил страницу к `#lead-form`
- **THEN** поля формы видны, кнопка «Отправить заявку» неактивна, виден текст «Чтобы отправить заявку, включите JavaScript или позвоните нам: +375 (29) 123-45-67.», а введённые имя и телефон не попадают в адресную строку

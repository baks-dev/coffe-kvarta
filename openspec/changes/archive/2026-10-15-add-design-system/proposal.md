# Proposal

## Why

Главное требование ТЗ к виду: сайт должен выглядеть как работа студии для конкретной обжарки «Кварта», а не как типовой сгенерированный лендинг. Сейчас в проекте стоит заглушка `create-next-app`: шрифты Geist без кириллицы, нейтральные `zinc`-цвета, тёмная тема по `prefers-color-scheme`, `lang="en"`. Секции (задача 04) и форма (задача 05) начнутся в ближайшее время. Если к их старту фирменных токенов и базовых компонентов не будет, цвета и отступы разойдутся по разметке, и требование «токены в одном месте, без хардкода» станет невыполнимым без переделки.

## What Changes

- Фирменная палитра «Кварты» по макету `images/design/design.png`: тёплый кремовый фон, почти чёрный текст, приглушённый вторичный текст, эспрессо для тёмных блоков, лаймовый акцент для главного CTA подписки. Все цвета задаются семантическими токенами в одном месте: в `@theme` в `src/app/globals.css`.
- Токены радиусов, теней, контейнера, отступов секций и типографической шкалы (H1–H3, текст, надзаголовки) в том же `@theme`.
- Единый видимый фокус с клавиатуры для всех интерактивных элементов, включая светлое кольцо на тёмных блоках.
- Шрифты через `next/font/google` с подмножеством `cyrillic`: один шрифт с засечками для заголовков, один гротеск для текста. Geist удаляется.
- **BREAKING (визуально)**: тёмная тема по `prefers-color-scheme` удаляется. Остаётся один фирменный вид (переключение тем лежит в бэклоге). `<html lang>` меняется на `ru`.
- Точечно подключаются компоненты shadcn/ui, перекрашенные в токены: Button, Input, Textarea, RadioGroup, Sonner (toast). Остальные не ставятся.
- Текстовый логотип «Кварта» как отдельный компонент.
- Контраст текста ≥ 4.5:1 для всех пар «текст/фон» из палитры. Серый текст из макета (`#727067`, 4,25:1 на кремовом) затемняется, чтобы пройти порог.

Вне рамок: вёрстка секций лендинга (задача 04), логика формы, валидация и состояние загрузки кнопки (задача 05), анимации (задача 10), переключение тем, рукописные надписи-акценты из макета (см. design.md, Open Questions).

## Capabilities

### New Capabilities
- `design-system`: визуальный контракт сайта: единый источник дизайн-токенов (цвета, типографическая шкала, радиусы, тени, контейнер), фирменные шрифты с кириллицей, один фирменный вид без тёмной темы, базовые UI-компоненты на токенах, текстовый логотип, видимый фокус и минимальный контраст текста.

## Impact

- **Код**: `src/app/globals.css` (токены, удаление тёмной темы), `src/app/layout.tsx` (шрифты, `lang="ru"`, `Toaster`), новые `src/components/ui/*` (button, input, textarea, radio-group, sonner), `src/components/logo.tsx`, `src/lib/utils.ts` (`cn`), `components.json` (конфиг shadcn).
- **Зависимости**: `class-variance-authority`, `clsx`, `tailwind-merge`, `sonner`, `@radix-ui/react-radio-group`, `@radix-ui/react-slot` (точный набор определит CLI shadcn), `tw-animate-css` при необходимости.
- **Задачи-потребители**: 04 (секции) и 05 (форма) используют токены и компоненты отсюда; 10 (a11y/перф) опирается на `display: swap` и контраст.
- **Заглушка `src/app/page.tsx`** останется до задачи 04. Её `zinc`/`dark:`-классы не входят в требования этого изменения.

# Proposal

## Why

Проект требует наполнения реальным контентом и структурированными данными для запуска MVP. На данный момент отсутствуют данные о продуктах, контактная информация, тексты секций и изображения, что блокирует завершение разработки интерфейсов.

## What Changes

- Создать базу данных продуктов с типизацией (Zod/TypeScript) в `src/data/products.json`
- Создать данные сайта (адрес, часы, контакты, условия доставки и самовывоза) в `src/data/site.ts` (включая siteName="Кварта")
- Написать тексты основных секций на русском языке в `src/data/content.ts`
- Подготовить оптимизированные изображения для веб-использования в `public/images/`
- Создать скрипт валидации данных `scripts/validate-data.ts` и настроить скрипт build
- Добавить зависимости `zod` и devDependencies `tsx`

## Capabilities

### New Capabilities

- `content-and-data`: хранилище контента и данных сайта — продукты, контакты, тексты, изображения

### Modified Capabilities

- (нет)

## Impact

- Новые файлы в `src/data/`, `src/lib/`, `scripts/`
- Новые изображения в `public/images/`
- Зависимость `zod` для валидации данных, devDependency `tsx` для запуска TS-скриптов

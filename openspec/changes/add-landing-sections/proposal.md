# Proposal

## Why

Сейчас на главной странице лежит заглушка `create-next-app` (`src/app/page.tsx`). Дизайн-система (02) и данные сайта (03) готовы, но у посетителя из рекламы ничего нет: ни ассортимента с ценами, ни подписки, ни доставки, ни контактов. ТЗ требует все эти блоки. Без секций нельзя встроить форму (05), настроить SEO (09) и замерить Lighthouse (10). Задача 04 — следующая по графику, её ждут 05, 09 и 10.

## What Changes

- Заглушку `src/app/page.tsx` заменяет лендинг из статических серверных секций. Страница экспортирует `ensureStatic = 'navigation'`: так Next.js 16 на этапе `next build` проверяет, что весь маршрут `/` пререндерится без работы во время запроса (SSG).
- Секции в таком порядке: шапка со sticky CTA «Оставить заявку» → hero → ассортимент → «Кто мы» и таймлайн свежести → подписка → доставка и самовывоз → оболочка формы заявки → контакты с Яндекс.Картой → подвал.
- Шапка: логотип, якорная навигация (от 1024 px) и кнопка «Оставить заявку», которая всегда видна, в том числе на 360 px. Обходимся без клиентского JS и бургер-меню.
- Карточки товаров (3 сорта + дрип-пакеты) берут данные из `getProducts()`. Цены в разметку не вписываются. Кнопка «Хочу» ведёт к форме и передаёт намерение (`interest: 'order'`, `productId`). CTA подписки передаёт `interest: 'subscription'`.
- Появляется клиентский контракт намерения заявки `src/lib/lead-intent.ts` (событие + отложенное намерение) и единственный клиентский компонент секций `LeadIntentLink`. Форма из задачи 05 подписывается на этот контракт и сама предзаполняет поле «Что интересует».
- Оболочка секции формы `#lead-form`: заголовок, три шага «как это работает», слот `children` для формы из 05 и всегда видимая строка «Удобнее позвонить?» с телефоном.
- Контакты: адрес, телефон (`tel:`), почта (`mailto:`), часы работы и встроенный виджет Яндекс.Карт (`iframe`, `loading="lazy"`, без JS SDK) со ссылкой «Открыть в Яндекс Картах».
- Две рукописные надписи из макета («Свежая обжарка каждую неделю», «С любовью к хорошему кофе») делаются SVG-контурами, полученными из шрифта Caveat одноразовым скриптом. На странице они выводятся через CSS-маску цветом токена. Шрифт на сайт не подключается.
- Тексты всех секций переписываются и сводятся в `src/data/content.ts`. H1 меняется на «Кофе, который приезжает свежим», как в макете. Метаданные изображений собираются в `src/data/images.ts`. В `src/data/site.ts` добавляются координаты мастерской для карты.
- Удаляются файлы заглушки `public/next.svg` и `public/vercel.svg`.
- В README появляются допущения этого change.

## Вне scope

- Поля формы, валидация, отправка и состояния формы (05). Здесь только оболочка секции и контракт предзаполнения.
- API `POST /api/lead`, UTM-атрибуция, Telegram (06–08).
- Metadata, OG-картинка, JSON-LD, robots/sitemap, аналитика (09). `metadata` в `layout.tsx` не трогаем.
- Анимации появления, skip-link, замер Lighthouse и тонкая настройка производительности (10). Здесь только базовые правила: `sizes` у изображений, `preload` только у hero, никакого лишнего клиентского JS.
- Автотесты (11): тестового стека в проекте пока нет, проверка идёт сборкой, поиском по исходникам и ручными сценариями.
- Корзина, иконка корзины из макета, онлайн-оплата, бургер-меню, тёмная тема, i18n.
- Отдельные страницы товаров и ссылка «Весь ассортимент»: все товары уже на главной.

## Capabilities

### New Capabilities

- `landing-page`: состав, порядок и поведение секций главной страницы: шапка со sticky CTA, hero, ассортимент, «Кто мы» и свежесть, подписка, доставка и самовывоз, оболочка формы, контакты с картой, подвал. Сюда же входят статический рендеринг маршрута `/`, адаптивность 360–1440 px, якорная навигация и контракт намерения заявки («Хочу» → форма).

### Modified Capabilities

- `content-and-data`: меняются требования «Система предоставляет тексты секций» (полный набор текстов лендинга, новый H1) и «Система предоставляет данные сайта» (координаты мастерской `geo`). Добавляется требование о едином реестре метаданных изображений.

## Impact

- **Новые файлы:** `src/components/sections/*.tsx` (header, hero, products, about, subscription, delivery, lead-section, contacts, footer), `src/components/section.tsx`, `src/components/product-card.tsx`, `src/components/lead-intent-link.tsx`, `src/components/handwriting.tsx`, `src/lib/lead-intent.ts`, `src/lib/format.ts`, `src/lib/yandex-map.ts`, `src/data/images.ts`, `scripts/build-handwriting.ts`, `public/handwriting/fresh-weekly.svg`, `public/handwriting/with-love.svg`.
- **Изменяемые файлы:** `src/app/page.tsx` (полная замена), `src/data/content.ts`, `src/data/site.ts`, `package.json` (devDependencies `opentype.js`, `@types/opentype.js`, скрипт `build:handwriting`), `pnpm-lock.yaml`, `README.md`, `public/images/README.md`.
- **Удаляемые файлы:** `public/next.svg`, `public/vercel.svg`.
- **Зависимости:** runtime-зависимостей не добавляется. Две devDependency нужны только для одноразовой генерации SVG.
- **Внешние сервисы:** виджет `yandex.ru/map-widget/v1/` в `iframe`. Загружается лениво и на первый экран не влияет.
- **Следующие задачи:** 05 вставляет форму в слот `LeadSection` и подписывается на `lead-intent`. 09 и 10 работают с готовой страницей.

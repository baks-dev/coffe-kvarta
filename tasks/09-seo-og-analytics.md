# 09. SEO, превью ссылок, аналитика

**Приоритет:** P1 · **Оценка:** 30 мин

## Подзадачи
- [ ] Next.js Metadata API: title, description, canonical, `lang="ru"`
- [ ] OG/Twitter: `opengraph-image` (картинка 1200×630, заголовок, описание) — проверить превью в Telegram
- [ ] JSON-LD `LocalBusiness`/`CoffeeShop` (адрес, часы)
- [ ] `robots.ts`, `sitemap.ts`, favicon
- [ ] Яндекс.Метрика + GA4 через `next/script` (`afterInteractive`), ID из env, цель на успешную отправку формы
- [ ] Vercel Analytics + Speed Insights
- [ ] Не блокировать рендер скриптами (влияет на Lighthouse)

- Ссылка в Telegram/WhatsApp показывает картинку, заголовок, описание.

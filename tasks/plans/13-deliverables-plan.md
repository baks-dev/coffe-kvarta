## Выбор хранилища

**Выбрано:** Upstash Redis вместо JSON файла

**Почему:**
- На Vercel ФС read-only (не подходит JSON)
- Serverless не сохраняет состояние между вызовами
- Redis даёт atomic dедупликацию через SET NX EX
- Free tier Upstash достаточно для лендинга
- Легко экспортировать данные (dump в консоли)

**Альтернативы:** Turso (SQLite), Neon (PostgreSQL), но Redis проще для простого кейса

## Как запустить и тестировать локально

### Установка

```bash
# Клонировать репозиторий
git clone <repo-url>
cd coffe-kvarta

# Установить зависимости
pnpm install

# Создать .env.local (скопировать из .env.example)
cp .env.example .env.local

# Добавить Upstash Redis переменные:
# UPSTASH_REDIS_REST_URL=...
# UPSTASH_REDIS_REST_TOKEN=...

# Добавить Telegram переменные (опционально):
# TELEGRAM_BOT_TOKEN=...
# TELEGRAM_CHAT_ID=...
```

### Запуск dev сервера

```bash
pnpm dev
# Открить http://localhost:3000
```

### Запуск тестов

```bash
# Unit и интеграционные тесты
pnpm test

# E2E тесты
pnpm test:e2e

# Все вместе
pnpm test && pnpm test:e2e
```

### Проверка качества кода

```bash
pnpm lint      # ESLint + Prettier
pnpm typecheck # TypeScript strict mode
```

### Сборка

```bash
pnpm build     # Создаст .next/
pnpm start     # Запустит production сборку
```

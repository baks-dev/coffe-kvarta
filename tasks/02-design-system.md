# 02. Дизайн-система и тема

**Приоритет:** P0 · **Оценка:** 45 мин

## Цель
Визуальная идентичность «Кварты», не похожая на типовой AI-лендинг (главное требование ТЗ). Ориентир — `images/design/design.png`.

## Подзадачи
- [ ] Изучить `images/design/design.png`, выписать палитру, типографику, сетку
- [ ] Кастомная тема Tailwind: цвета (токены), радиусы, тени, контейнер
- [ ] Шрифты через `next/font` (кириллица обязательна; 1 шрифт для заголовков + 1 для текста)
- [ ] Базовые компоненты (shadcn/ui точечно: Button, Input, Select/Radio, Textarea, Sonner-toast) — только нужные
- [ ] Текстовый логотип «Кварта»
- [ ] Тон: тёплый, простой, без «премиального глянца»

## Не делаем
Переключение тем (`next-themes`) — один фирменный вид, см. бэклог.

## Критерии приёмки
- Токены в одном месте, компоненты используют их, не хардкод.
- Контраст текста ≥ 4.5:1.

# 08. Дублирование заявки в Telegram (плюс)

**Приоритет:** P1 · **Оценка:** 20 мин

## Подзадачи
- [ ] Бот через @BotFather, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` в env
- [ ] Отправка прямым `fetch` к Bot API `sendMessage` (вместо telegraf — для одного вызова библиотека избыточна и тяжела для serverless)
- [ ] Формат сообщения: имя, телефон, интерес, комментарий, источник (UTM), страница; экранировать HTML
- [ ] Сбой Telegram **не** должен ронять заявку: заявка уже сохранена, ошибка логируется
- [ ] Таймаут запроса (напр. 3 с)

## Критерии приёмки
- Заявка приходит в чат менеджера; при неверном токене форма всё равно успешна.

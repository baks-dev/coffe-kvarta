# 05. Форма заявки (UI)

**Приоритет:** P0 · **Оценка:** 45 мин

## Поля
Имя, телефон, что интересует (подписка / разовый заказ / вопрос), комментарий.

## Подзадачи
- [ ] Zod-схема в `src/lib/lead-schema.ts` — **общая** для клиента и сервера
- [ ] Валидация белорусского номера: `+375 (25|29|33|44) XXX-XX-XX` (+ допустимые форматы `80…`, `375…`), нормализация к `+375XXXXXXXXX`
- [ ] Маска/подсказка ввода, понятное сообщение: «Введите номер в формате +375 29 123-45-67»
- [ ] react-hook-form + zodResolver, ошибки под полями
- [ ] Состояния: idle / sending (кнопка disabled, защита от двойного клика) / success / error
- [ ] Ошибка отправки: видимое сообщение + что делать («попробуйте ещё раз или позвоните: …») + toast
- [ ] Предзаполнение «интереса» из карточек товара и подписки
- [ ] Честный текст про повторную заявку при ответе `duplicate`

## Критерии приёмки
- Неверный номер не уходит на сервер; подсказка понятна.
- Двойной клик даёт один запрос.
- Сетевой сбой показывает ошибку, данные формы сохраняются.
